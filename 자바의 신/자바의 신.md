# 자바의 신

1. 클래스가 무엇인가?
    
    ```
    객체를 만들기 위한 설계도이다.
    변수(속성)와 메소드(기능)를 묶어 놓은 단위
    ```
    
2. 메소드가 무엇인가?
    
    ```
    어떤 기능을 수행하는 코드 묶음
    입력을 받아 처리하고 결과를 반환할 수 있다
    ```
    

1. 메소드의 매개 변수는 어디에 적어주는가?
    
    ```
    메소드 이름 뒤 괄호( )안에 적는다.
    ```
    

1. 메소드 이름 앞에 꼭 적어 줘야 하는것은?
    
    ```
    리턴 타입(return type)
    메소드가 어떤 값을 돌려주는지 표시
    
    int sum()
    void print()
    ```
    

1. 클래스가 갖고 있어야 하는 두 가지
    
    ```
    변수(속성) + 메소드(기능)
    ```
    
2. 메소드에서 결과를 돌려줄 때 사용하는 예약어
    
    ```
    return
    ```
    

### 📍 컴파일

→ 내가 만든 프로그램 코드를 컴퓨터가 이해할 수 있도록 엮어주는 작업

👇 자바 컴파일 및 실행 절차

![자바 컴파일 절차.png](%EC%9E%90%EB%B0%94%EC%9D%98%20%EC%8B%A0/%E1%84%8C%E1%85%A1%E1%84%87%E1%85%A1_%E1%84%8F%E1%85%A5%E1%86%B7%E1%84%91%E1%85%A1%E1%84%8B%E1%85%B5%E1%86%AF_%E1%84%8C%E1%85%A5%E1%86%AF%E1%84%8E%E1%85%A1.png)

- .java 라는 확장자로 되어 있는 소스를 컴파일하면 .class라는 확장자를 가진 파일이 생성되어 디스크에 저장된다.
- .class 파일은 바이너리 파일로 되어 있기 때문에 에디터에서 열어도 제대로 보기가 어렵다.
- 컴파일을 하는 프로그램을 컴파일러라고 부르며, 자바에서는 javac.exe라는 프로그램(맥이나 리눅스에서는 그냥 javac)이 그 역할을 수행한다.
- 컴파일을 마친 클래스 파일은 JVM에서 읽어서 운영체제에서 실행된다.

```bash
# 명령어
$ javac [.java 파일명]
```

### 📍main 메소드

모든 자바 클래스는 main() 메소드가 반드시 있어야 한다.

```java
public static void main(String[] args) {}
```

- public : “접근 제어자”
- static : “정적인” , static으로 선언하면 객체를 생성하지 않아도 호출할 수 있다.
- void : 메소드 이름 앞에는 그 메소드가 어떤 값을 넘겨줄지 정한다.
- main : 메소드(method) 이름이다. 대소문자 구분도 하여 반드시 이 이름으로 써야한다.
- (String [] args) : 매개 변수(parameter), main() 메소드에 전달되는 매개 변수는 반드시 String[] args!!, [ ]는 args 변수가 배열

### 📍 객체지향 언어(Object Oriented Language, OOP)

**정의**

> 객체지향 언어는 데이터를 객체 단위로 묶고, 객체 간 상호작용으로 프로그램을 구성하는 방식이다.
> 

**핵심 개념 4가지**

👉 캡슐화 - 데이터와 메소드를 하나로 묶고 외부 접근을 제한

👉 상속 - 기존 클래스를 재사용해 확장

👉 다형성 - 같은 인터페이스로 다른 동작 수행

👉 추상화 - 핵심 기능만 드러내고 내부 구현 숨김

❣️ 왜 쓰는가?

- 유지보수 쉬움
- 코드 재사용성 증가
- 확장성 좋음

> 객체지향은 현실 세계를 객체로 모델링해서 구조적으로 프로그램을 설계하는 방식이다.
> 

### 📍 생성자(Constructor)

**정의**

> 객체가 생성될 때 자동으로 실행되는 초기화 메소드
> 

**특징**

✔️ 클래스 이름과 동일

✔️ 반환 타입 없음

✔️ 필드 초기화 목적

✔️ 반드시 직접 작성할 필요는 없다. → 기본 생성자는 자동으로 생성

> 생성자는 객체 생성 시 초기 상태를 설정하기 위해 호출된다.
> 

### 📍 클래스(class)

**정의**

> 객체를 만들기 위한 설계도
> 
- 속성(변수)
- 기능(메소드)

> 클래스는 객체가 가져야 할 데이터와 행동을 정의한 틀이다.
> 

### 📍 객체(Object) 혹은 인스턴스(instance)

**정의**

> 클래스를 기반으로 실제로 생성된 인스턴스
> 

👉 클래스 = 설계도

👉 객체 = 실제 제품

👉 인스턴스 = 그 객체가 메모리에 존재하는 상태를 강조하는 표현

> 객체는 클래스의 구조를 기반으로 메모리에 생성된 실체이다.
객체와 인스턴스는 거의 같은 의미로 쓰이지만, 인스턴스는 클래스와의 관계를 강조하는 표현이다.
> 

❣️ 객체 vs 인스턴스

👉 객체 → 결과물 관점

👉  인스턴스 → 클래스 기준 관점

예시 설명:

> “Car 클래스의 인스턴스를 생성했다” = Car 객체를 만들었다
>

### 📍 변수(variable)

| 구분 | 선언 위치 | 소속 | 생명주기 | 저장 영역 | 특징 |
| --- | --- | --- | --- | --- | --- |
| **지역 변수** | 메소드 내부 | 메소드 | 메소드 실행 동안 | 스택(Stack) | 반드시 초기화 필요 |
| **매개 변수** | 메소드 괄호 | 메소드 | 호출 ~ 종료 | 스택(Stack) | 전달값 저장 |
| **인스턴스 변수** | 클래스 내부 | 객체 | 객체 생성 ~ GC | 힙(Heap) | 객체마다 따로 존재 |
| **클래스 변수** | static 선언 | 클래스 | 프로그램 종료까지 | 메소드 영역 | 모든 객체 공유 |

> 지역/매개 변수는 메소드 실행 동안만 존재하고, 인스턴스 변수는 객체와 함께 살아 있으며, 클래스 변수는 프로그램 전체에서 공유된다.
> 

- 지역 변수(local variables)
    
    정의
    
    > 중괄호 내에서 선언된 변수 = 메소드 내부에서 선언되는 변수
    지역 변수를 선언한 중괄호 내에서만 유효
    > 
    
    특징
    
    - 메소드 실행 시 생성
    - 종료되면 자동 소멸
    - 초기화 필수
    
    생명주기
    
    👉 메소드 호출 → 생성
    
    👉 메소드 종료 → 소멸
    
    ```java
    public class VariableTypes {
            int instanceVariable;
            static int classVariable;
            public void method(int parameter) {
                    int localVariable;  // 지역변수 1
            }
            public void anotherMethod() {
                    int localVarialbe;  // 지역변수 2
            }
    }
    ```
    
    → 지역변수 1과 지역변수 2는 서로 다른 변수이다.
    
- 매개 변수(parameters)
    
    정의
    
    > 메소드에 넘겨주는 변수 = 메소드 호출 시 전달받는 변수
    메소드가 호출될 때 생명이 시작되고, 메소드가 끝나면 소멸
    > 
    
    특징
    
    - 지역 변수의 일종
    - 전달값 저장
    - 메소드 종료 시 소멸
    
    생명주기
    
    👉 메소드 호출 → 생성
    
    👉 메소드 종료 → 소멸
    
- 인스턴스 변수(instance variables)
    
    정의
    
    > 객체마다 따로 존재하는 변수
    > 
    
    메소드 밖에, 클래스 안에 선언된 변수, 앞에는 static이라는 예약어가 없어야 한다.
    
    객체가 생성될 때 생명이 시작되고, 그 객체를 참조하고 있는 다른 객체가 없으면 소멸
    
    특징
    
    - 객체 생성 시 힙에 생성
    - GC 대상
    - 자동 초기화
    
    생명주기
    
    👉 new 객체 생성 → 생성
    
    👉 GC → 소멸
    
- 클래스 변수(class variable)
    
    정의
    
    > 클래스에 속하며 모든 객체가 공유하는 변수
    인스턴스 변수처럼 메소드 밖에, 클래스 안에 선언된 변수 중에서 타입 선언 앞에 static이라는 예약어가 있는 변수
    클래스가 처음 호출될 때 생명이 시작되고, 자바 프로그램이 끝날 때 소멸
    > 
    
    특징
    
    - static 키워드 사용
    - 한 번만 생성
    - 프로그램 종료까지 유지
    
    생명주기
    
    👉 클래스 로딩 → 생성
    
    👉 프로그램 종료 → 소멸
    

💻 전체를 한 번에 보는 코드 예제

```java
class Person {

    static int population = 0;   // 클래스 변수

    String name;                 // 인스턴스 변수

    Person(String name) {        // 매개 변수
        this.name = name;
        population++;
    }

    void introduce() {
        int age = 20;            // 지역 변수

        System.out.println(name + " " + age);
    }
}

public class Main {
    public static void main(String[] args) {
        Person p1 = new Person("Tom");
        Person p2 = new Person("Jane");

        p1.introduce();
        p2.introduce();

        System.out.println(Person.population);
    }
}

```

👉 스택(Stack)

역할

- 메소드 실행 관리
- 지역 변수 / 매개 변수 저장

특징

✔️ 스레드별 독립

✔️ LIFO 구조

✔️ 빠름

✔️ 자동 정리

생성/소멸

> 메소드 호출 → 생성
메소드 종료 → 즉시 제거
> 

👉 힙(Heap)

역할

- 객체 저장

특징

✔️ 모든 스레드 공유

✔️ GC 대상

✔️ 상대적으로 느림 → 동적 메모리 관리 + GC 때문

생성/소멸

GC → 소멸
>
